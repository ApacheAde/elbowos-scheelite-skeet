# Scheelite Skeet

Full-colour Python 3 neon skeet-gallery arcade for [ElbowOS](https://x.com/ElbowOS).

Aim the magenta turret. Blast gold scheelite clays and rare UV-cyan discs as they arc across the well. Streaks stack. A / D or arrows aim. Space / W / Up fire.

## Play

```
pip install -r requirements.txt
python3 scheelite_skeet.py
```

## Record a 9:16 reel

```
python3 scheelite_skeet.py --record
```

Writes `scheelite_skeet_ElbowOS.mp4` (1080x1920, 15s, 30fps, h264).
